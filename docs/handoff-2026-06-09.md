## 7. 关键决策记录(别推翻)

- **不用压缩包分发**:离线更新崩、Windows symlink 需管理员、易把敏感文件打包。用 git。
- **去掉 MCP**:数据是本地 markdown,AI 直接读更自然;MCP 是多余一层 + 跨平台配置/GUI env 注入坑。内核 `wiki_core`/`wiki-cli` 保留。(注:"跨平台 MCP 配置麻烦"这条理由因三家都有插件市场而弱化,但去 MCP 整体仍成立。)
- **sync-team = 原样镜像,不重分类/不学习**(用户拍板):团队知识镜像进个人库 `team/` 只读区,可检索、不参与个人库 lint。
- **三个"同步"语境**:`sync-team`(个人库主线)/ `changes`(WIKI_ROOT=团队clone)/ `wiki-sync`(团队clone, `--ff-only`)。
- wiki-cli 调用约定:skills/commands 用 `${CLAUDE_PLUGIN_ROOT}/tools/bin/wiki-cli`;规则指针用 `{{WIKI_MANAGE}}/.../wiki-cli` 完整路径(wiki-cli 不在 PATH)。
